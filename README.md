# 戏境

面向院团、文旅与公共文化机构的传统演艺场景方案展示原型。三个连续板块：智能导赏、沉浸展演、虚实互动。

## 浏览与更新

在线地址：https://ssir-creator.github.io/xiqu-web/

推送到 main 后，GitHub Actions 自动发布，更新后刷新同一网址即可。若有缓存，用 Ctrl+F5 刷新。

## 单文件与离线

index.html 包含全部图片、样式与脚本，可直接用 Chrome 或 Edge 打开，无后端、数据库或 CDN。中文朗读使用设备的中文语音，本机声音可离线使用，系统在线声音需要网络；没有中文声音时可查看文字稿。麦克风需浏览器支持及主动授权。

## 展示路径

开场由小戏介绍研究项目及专业机构定位，再衔接简短演前导赏、同一剧目的数字展演、跟唱与意象生成。支持连续讲解、暂停、上一步、下一步及自由浏览。讲稿见 [讲解脚本.md](讲解脚本.md)。

智能导赏不放图片，只保留剧目、人物关系、背景及三个观演重点。所选剧目延续到展演与参与环节。

沉浸展演采用完整双人数字场景，人物不切成拼贴素材；字幕、光效和节奏组织情境，画面不是原剧演出录像。

虚实互动仅含跟唱与意象生成。跟唱支持选择本机已获授权的唱段、播放、调速、循环，以及麦克风声音能量反馈；不录音、不上传、不评价唱腔准确度。练声示意不是专业唱腔。意象按本地规则组合完整场景、情绪、天气、光景和用户文字，可保存 PNG 或八秒无声视频；不声称接入在线生成模型。

## 本地预览

运行 `python3 -m http.server 8080`，访问 http://localhost:8080/ 。HTTPS 或 localhost 可支持麦克风权限。连贯展示不自动申请麦克风、不自动下载文件。
