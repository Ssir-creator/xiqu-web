# 戏境

传统演艺多模态体验网站，包含智能导赏、沉浸展演、跨媒介叙事与虚实互动。

## 在线发布

推送到 `main` 后，GitHub Actions 自动发布到 GitHub Pages。
默认站点地址为 `https://ssir-creator.github.io/xiqu-web/`，以成功部署输出的地址为准。

首次发布如提示 Pages 尚未启用，在仓库 Settings → Pages 中选择 **GitHub Actions**，然后重新运行 `Publish Xijing website` 工作流。

后续更新同一仓库的 `index.html`，推送到 `main` 即可更新固定网址。部署完成后刷新网页；如果看到缓存内容，可用 Ctrl+F5 强制刷新。

## 离线使用

下载 `index.html` 后用 Chrome 或 Edge 打开。图片、样式与脚本均内嵌，无需安装依赖。小戏朗读使用设备提供的中文语音：本机中文声音可离线使用，系统在线声音需联网。
摄像头和麦克风由用户主动授权；功能介绍和按钮、触控体验无需联网。

## 本地预览

在仓库目录运行 `python3 -m http.server 8080`，在浏览器访问本地服务器。线上部署使用 HTTPS，有利于浏览器的摄像头与麦克风权限支持。

## 专业场景讲解与连贯展示

进入网页先显示项目导入。点击“听小戏讲解并开始展示”，小戏依照固定脚本介绍项目定位，再自动展开智能导赏、沉浸展演、跨媒介叙事、虚实互动及声、律、形、意，最后回顾整条展示逻辑。支持暂停、继续、上一环节、下一环节和自由浏览。

完整讲稿见 [讲解脚本.md](讲解脚本.md)，依据用户提供的结项研究报告编写。平台定位为面向院团、文旅和公共文化机构的场景方案展示与交互验证原型，不宣称专业唱腔或姿态评测。

讲稿与统一的写实数字角色全部内嵌在 `index.html`；讲稿文档不是网页的外部依赖。连贯展示不会自动申请摄像头或麦克风，也不会自动下载或上传用户内容。

## 中文语音

旧版离线合成录音已移除。进入网站先在“小戏的中文声音”中选择声音并点击“试听中文”；仅接受标记为中文且非 eSpeak 的系统声音。没有中文声音时明确提示添加语音包，不使用英文声音或旧录音兜底。所有介绍与连续展示读取同一份固定中文讲稿。

## 演出前导赏

智能导赏以具体剧目为入口：先选择游园、断桥或同窗，了解人物关系、背景和三个观演重点，再携带所选线索进入同一剧目的沉浸展演。问答围绕当前剧目展开。水袖、折扇等知识收进相关辅助说明，不再以独立科普展板或泛化答题占据主页面。跨媒介叙事与连贯讲解同步保留剧目上下文。
